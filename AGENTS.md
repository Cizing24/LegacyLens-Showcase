# LegacyLens engineering rules

- Communicate in Traditional Chinese (Taiwan). Keep code identifiers in English.
- This is ASP.NET Web Forms / .NET Framework 4.8, not ASP.NET Core.
- Keep business rules in Application/Domain and ADO.NET access in Infrastructure.
- Use parameterized SQL, server authorization, CSRF protection, optimistic concurrency and transactions.
- Never commit credentials, private customer information, raw large datasets, database files or build output.
- Label evidence as authentic development issue, controlled fault injection, public dataset observation or synthetic scenario.
- Record commands and actual outcomes. A missing environment is not a passing test.
- This is an independently initialized showcase snapshot. Original baseline tags and development history remain private and are not included here.
- Keep this repository private until the owner changes visibility. Do not deploy or publish without authorization.
- Use small, verified commits and retain test and benchmark measurements. Never copy private audit evidence into this repository.
